# Claude 分镜交接

你负责在 Claude 中完成故事和分镜，再把结果交给 Codex。以下提示词可以直接附在故事后面。

## 给 Claude 的提示词

```text
请把我的故事转换为供 AI 短剧制作使用的分镜方案。

忠实保留故事、人物关系、关键动作、对白和结局。不得为了凑镜头数量改写情节。
输出以下内容：

1. 完整剧本：标注场次、地点、时间、角色、动作、说话人及准确台词。
2. 人物设定表：每个人物使用固定编号 C01、C02……；写明年龄、脸型、发型、
   体型、辨识特征。服装另列编号 O01、O02……，同一段连续情节服装一致。
   同一人物的不同年龄、梦境或伪装版本注明哪些身份特征必须保留。
3. 场景设定表：每个物理空间使用固定编号 L01、L02……；说明门窗、家具、
   主要道具的相对位置、材质、光线和色调。同一房间不同机位沿用同一编号。
4. 按剧情顺序的逐镜头分镜，每镜包含：
   - 镜头编号、所属场次、预计秒数；
   - 人物编号、服装编号、场景编号；
   - 景别、机位、构图、运镜；
   - 首帧静态画面：只描述动作开始时可见的一幅画面；
   - 视频中的动作和表情变化，及动作结束状态；
   - 逐字对白、说话人、语气、停顿，注明画外音或电话音；
   - 环境音；
   - 与前后镜头的连续性要求：站位、视线、道具、动作、光线、服装。

每镜只承担一个清晰的主要动作。根据对白长度安排时长，不将长台词硬塞进短镜头。
计划通过可灵批量生成的镜头使用 3–15 整数秒；确需更长时拆镜，不删除台词。
首帧描述与视频动作描述分开；首帧不能是多格漫画、时间序列或角色设定拼图。
不要把人物名字当作外貌一致性的保证。相同角色和空间始终引用同一编号。
不确定的创作选择单列“待确定”，不要伪装成原故事已有设定。
```

## 交给 Codex 后的制作顺序

1. 校验分镜完整性、对白、时长和跨镜头连续性，映射到项目中的角色及服装 ID。
2. 导入外部分镜，直接保存原稿，不调用文本模型重新拆分。
3. 生成角色母版与必要的服装参考；固定场景母版及布局。
4. 用对应的人物、服装和场景图片作为实际输入，生成每镜首帧。
5. 保存图片来源、引用关系和镜头版本，交给 AI Drama Studio 的视频任务。
6. 跟踪视频任务、保存结果及失败原因，修复时按镜头处理。

第 3–4 步的 GPT 生图接入方式尚待选择：OpenAI API 自动批量调用，或由 Codex
在对话中调用生图工具后导入。当前应用原有的图片任务使用可灵，不应称为 GPT 生图。
本次新增的是第 2 步的导入入口；尚未完成 GPT 到视频的全链路实测。
图片作为参考能够约束一致性，但仍需检查生成结果的人脸、服装及空间布局。

## 应用中的导入入口

“故事与审阅” → “导入 Claude / 外部分镜”。选择目标分集后粘贴 JSON，导入为新稿。
已经进入制作的分集继续使用原来的“撤回分镜”修订流程。

JSON 使用现有 StoryDraft 格式；Codex 负责将 Claude 的表格转换为此结构。
若直接让 Claude 输出 JSON，需先提供当前项目真实 character_id / outfit_id。
场景与镜头数据库 id 省略；每场 order_index 从 1 连续编号。

```json
{
  "title": "雨夜来信",
  "source_idea": "一封匿名信打断了她的夜班。",
  "draft": {
    "screenplay": "办公室，夜。雨打在玻璃上。桌上放着一封尚未拆开的信。",
    "scenes": [
      {
        "location": "办公室",
        "time_of_day": "夜",
        "summary": "信封的空镜",
        "shots": [
          {
            "order_index": 1,
            "duration": 5,
            "characters": [],
            "shot_type": "特写",
            "camera_angle": "俯视",
            "camera_movement": "缓慢推进",
            "composition": "信封位于画面中央，台灯在左侧",
            "visual_description": "台灯照亮木桌上的白色信封，信封尚未打开。",
            "action": "镜头缓慢推近信封",
            "dialogue": "",
            "generation_prompt": "保持首帧办公室布局。镜头缓慢推近桌上未拆封的信，背景只有雨声，无人声。",
            "generation_mode": "image_to_video",
            "continuity_requirements": ["保持信封位置和台灯光线"]
          }
        ]
      }
    ]
  }
}
```

API：`POST /api/v1/projects/{project_id}/external-storyboards?episode_id=...`。
请求体在上面 JSON 基础上增加 UUID `request_token`。同一标识和相同内容重复提交只返回
原稿；同一标识换内容返回 409。导入不会自动批准分镜或调用收费生成接口。
