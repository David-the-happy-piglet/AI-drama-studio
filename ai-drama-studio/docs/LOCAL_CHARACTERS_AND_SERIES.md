# 本地角色与剧集整理

## 使用角色同步

1. 选择项目 → 角色资产 → “参考图与可灵主体”。
2. 上传清晰正面母版及 1–3 张不同角度参考图，点击“保存参考图到本地”。此步骤不请求可灵。
3. 检查预览、主体名和短描述，勾选审阅与上传确认，再点击创建。只上传图片和该描述，不发送剧本。
4. 等待主体创建，或手动“刷新主体状态”。关闭窗口不取消远端任务，状态保存在本地数据库。
5. 分镜指定角色后，镜头生成页默认自动引用就绪主体，并显示对应名称、ID 和提示词引用名。视频仍须独立确认生成。

没有母版图时可以先使用下方的候选图功能；生成图片和建立可灵主体是两个独立步骤。声音创建、视频型主体创建尚未实现。

如果任务结果不确定，先刷新查询，不要重复创建。API Key/区域变化或本地角色版本变化会阻止自动复用；按提示核实或重新审阅。

## 从母版 prompt 生成候选角色图

1. 角色资产 → 角色卡片“母版 prompt · 生成候选图”。优先读取分集当前剧本的 `preproduction.character_prompts[].portrait`，按角色 ID 匹配；无现成 prompt 时由角色资料整理。窗口里的编辑不修改原剧本。
2. 选择 1–4 张、1K/2K、3:4/1:1/2:3。默认 4 张、1K、3:4；勾选费用与文字发送确认后提交。使用已有 `KLING_API_KEY` / `KLING_BASE_URL`，配置就绪不代表图片模型权限或额度已验证。
3. 查看候选图历史，点击图片放大对比。候选图仅在保存到本地后可选用。不同候选不是同一人物的不同角度；双版本角色需要沿用同一张最终母版。
4. 点击“将选中图片设为母版”，确认替换。角色版本递增，旧补充图引用清空，旧可灵主体绑定因版本过期不可复用；原图片文件和选择前记录保留。不会自动创建可灵主体、生成视频或批准剧本。
5. 再到“补充参考图 / 创建可灵主体”补充同脸多角度素材并单独确认上传。

纯文字模式遵循 [Kling Image 3.0 文档](https://kling.ai/document-api/api/image/3-0-omni/image-generation.md)（2026-09-06 核验），`POST /v1/images/generations`、`model_name=kling-v3`。该模式只含当前 prompt、负向约束和生图参数，不上传图片，适合初始选角。已有母版图的角色现在默认进入下方参考图模式。

### 基于母版参考图生成（Image 3.0 Omni）

角色已有母版时，卡片入口为“基于母版参考图生成”，窗口默认选择参考图模式、1 张、1K。也可手动切换“纯文字生成新角色”，但必须重新确认；切换会恢复模式默认提示词和张数。

1. 查看“本次将上传的母版图”和图片指纹。只接受当前角色在当前项目中保存的 JPG/PNG 母版，10 MB 内、两边至少 300px、宽高比 2:5–5:2。
2. 选择正面、45° 半侧面、90° 侧面或全身预设，再编辑生成要求。预设描述单个角度；1–4 张是同一要求的候选，不是自动分配多个角度。全身照中原图未显示的细节可能由模型补全。
3. 勾选图片使用权、向可灵发送这张图片和提示词、API 费用确认，再生成。后端重新检查角色版本、母版路径和 SHA-256；缺失、损坏、跨项目或预览后被替换的图片会阻止提交，不能自动退化为纯文字。
4. 候选图沿用既有审阅、选择和设为母版流程，不自动替换原图。历史里可查看输入母版快照、指纹、完整有效提示词和模型；旧任务明确显示“纯文字生成 · 未使用母版图片”，不会被误标为参考图任务。

参考图调用遵循 [Omni Image Generation](https://kling.ai/document-api/api/image/3-0-omni/image-omni.md)：`POST /v1/images/omni-image`，`model_name=kling-v3-omni`，`image_list=[{"image":"<母版图片的纯 Base64>"}]`，`result_type=single`，`n=1..4`。完整 prompt 在开头加入 `<<<image_1>>>` 身份参考，负向约束并入 prompt（Omni 不传独立 `negative_prompt`），合计最多 2500 字。查询同接口 `GET /v1/images/omni-image/{task_id或external_task_id}`；不调用视频 `/tasks`，不自动重提超时任务，也不创建可灵主体。

在既有创建任务 API 上新增：`mode=reference`、`reference_path`、`reference_sha256`、`reference_confirmed=true`；值来自 `portrait-studio.reference`。有母版的角色必须显式传 `mode`，旧界面请求被拦截以避免继续误用纯文字。纯文字模式不能携带图片字段。任务新增一对一 `character_image_inputs` 表保存模式、有效 prompt、原路径、SHA-256、项目内输入快照路径；旧表无需改列，旧任务和原图不改动。幂等 token 同时绑定模式与母版指纹。API 返回不会包含 Base64 或密钥。

真实图片作为视觉参考不等于保证锁脸。当前接口没有使用不受支持的“人脸参考强度”参数，也没有自动批量多角度或自动加入补充参考图的功能。生成结果仍需人工核对身份、服装和细节。

可灵拒绝请求现在会保留 HTTP 状态、业务错误码、简短错误信息和请求 ID，并清除密钥或长图片数据。429 可据业务码进一步区分资源包问题、限流或并发问题；不自动扣费重试。

本地 API（统一加 `/api/v1` 前缀）：

- `GET /characters/{id}/portrait-studio`：母版 prompt、配置状态和最近 50 批历史。
- `POST /characters/{id}/portrait-jobs`：要求 `expected_version`、UUID `request_token`、`prompt`、`confirmed=true`；可选 `negative_prompt`、`count`、`resolution`、`aspect_ratio`。同角色相同 token 和参数不会重复调用可灵。
- `POST /characters/{id}/portrait-jobs/{job}/refresh`：查询原任务或重试下载，不重新生成。提交超时通过本地任务 ID（远端 `external_task_id`）找回；结果不确定时禁止同角色新提交。
- `POST /characters/{id}/portrait-jobs/{job}/select`：要求当前 `expected_version`、`candidate_index`、`confirmed=true`；旧版本候选额外要求 `accept_stale=true`。

任务持久保存在新增 `character_image_jobs` 表；并发提交和轮询使用数据库唯一约束/租约保护。关闭窗口不取消远端任务，重开后可刷新；自动轮询最多约四分钟。图片 URL 有效期以平台为准，文档当前注明 30 天，应及时刷新保存到本地。

下载只接受已核验可灵 CDN（`inkwai.com`、`klingai.com`、`klingai-cdn-aws.com` 及子域）的 HTTPS 地址，不跟随重定向，不向 CDN 发送 API Key。只保存 10 MB 内符合参考图尺寸的 PNG/JPEG 至项目素材目录；其他返回保留错误供核实，不能用任意 URL 绕过验证。若可灵新增 CDN，需核验后更新适配器。

## 后续创建其他类型剧集

在“项目”建立独立剧集，可填写类型；进入“分集目录”添加各集。打开某集的“故事与审阅”，新建的草稿自动关联该集。每集审阅稿独立，角色库按项目共享。
